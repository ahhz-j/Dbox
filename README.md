# Dbox

Disenchant helper addon for World of Warcraft Classic.

## Usage

1. Copy `Dbox.toc` and `Dbox.lua` into your `Interface/AddOns/Dbox/` folder.
2. In game, run either command:
   - `/dbox <item link>`
   - `/disenchant <item link>`
3. Shift-click an item into chat while typing the command to evaluate likely disenchant materials.
