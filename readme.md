# Dbox

Dbox 是一款面向“附魔分解”场景的轻量级效率工具，帮助你更快、更稳地完成背包装备的筛选、分拣与逐件分解。它专注于“流程清晰、操作可见、行为可控”，在不改变你的习惯前提下，让分解这件事变得更简单。

## 能做什么

- 识别并列出背包中可分解的装备（武器/护甲，品质≥绿），将其集中呈现在“可分解”列表中；
- 以双列表的方式管理“待分解 / 待排除”队列：单击选择、双击在两个队列间移转；
- 将“待排除”写入保存的排除表，后续扫描会自动跳过；可随时读取或清空该表；
- 以安全方式逐件执行分解：按钮只在条件满足时可用，失败或中断会自动回滚至队首；
- 在界面底部的信息栏中，随时看到关键统计：背包空格、可分解、待分解、待排除、已排除；
- 提供“设置”与“帮助”面板：更直观地调节界面与快速查看使用说明；
- 遇到异常时，一键“Reset”清理保存的数据，快速回到干净状态。

## 使用方式（推荐流程）

1. 输入 /dbox 打开界面（再输入一次可关闭）。
2. 点击左侧“扫描”，候选装备将出现在“可分解”。
3. 根据需要：
   - 直接点击“全部添加”，或逐件单击加入“待分解”；
   - 对不想分解的条目，双击放入“待排除”，再点击“全部写入”保存为排除表。
4. 在“待分解”中点击“执行分解”，逐件分解至背包。若分解失败或被打断，该条目会回到队首等待重试。
5. 需要时可通过“读取表单”查看已保存的排除表，或“清除表单”将其清空。

## 界面说明

- 标题栏
  - 左侧显示名称与版本号；右侧有“帮助 / 关闭”两个按钮（宽 40，帮助靠近关闭）。
  - “帮助”支持开关：再次点击关闭帮助面板；显示时与设置面板互斥。
  - “关闭”隐藏主界面；隐藏时联动关闭帮助与设置面板。
- 左侧菜单
  - 扫描：检测背包可分解装备；
  - Debug：切换调试标签（仅供排查）；
  - 设置：打开设置面板（可拖动，打开时对齐主界面右上角，关闭与帮助互斥）；
  - Reset：清空 Dbox 的保存数据（弹出确认后执行）。
- 四个容器（横向一行）
  - 可分解：扫描结果；
  - 待分解：将要执行分解的队列；
  - 待排除：不希望分解、将写入排除表的队列；
  - 已排除：已保存排除表的可视化列表（通过“读取表单”查看）。
  - 每个容器底部提供针对性的批量按钮（如“全部添加 / 全部清除 / 执行分解 / 全部写入 / 读取表单 / 清除表单”）。
- 信息栏
  - 从左到右依次显示：背包空格、可分解、待分解、待排除、已排除（白色数字高亮，实时刷新）。

## 行为特点

- 分解按钮的“可用”仅在条件满足时点亮：
  - 已学分解技能；不处于战斗/读条/引导；“待分解”非空；背包剩余空格大于 1；
  - 鼠标悬停时会显示具体原因（逐条列出）；
  - 点击后由安全宏发起分解，对队首条目逐件处理。
- 失败/中断的回滚：
  - 若施法失败/被打断，正在处理的条目将自动回到“待分解”队首；
  - 仅在事件明确告知失败时回滚，避免误判。
- 设置与帮助的“互斥与切换”：
  - 打开一个时自动关闭另一个；两个按钮再次点击均可关闭自身面板；
  - 设置与帮助的背景透明度与主界面一致，整体风格统一；标题字号读取设置，默认 14；
  - 设置默认在主界面右上角旁打开，且可拖动位置；首次点击设置前会先隐藏帮助避免重叠。

## 设置项（可在“设置”中调整）

- 界面尺寸：主界面高度、容器高度（主界面宽度与容器宽度由模式/默认控制，滑块禁用）；
- 样式参数：标题栏高度、主界面与承载栏的背景透明度；
- 操作距离：底部按钮承载栏的 Y 轴偏移；
- 文字字号：标题栏、容器标题、按钮文字、内容文字（范围 8–18，步进 1；标题默认 14）；
- 全局锁定：新增“锁定所有设置”开关，开启后禁用所有选项并灰化文本；
- 扫描过滤：可按品质开关（精良/稀有/史诗）筛选。

## Reset（重置）

- 左侧菜单中的“Reset”用于清除本插件在 WTF 存储的所有数据（包括排除表与配置）；
- 点击会弹出确认对话框，选择“是”后立即清除并刷新界面。

## 兼容性与特点

- 兼容新版与旧版的背包 API：自动在 C_Container 与旧接口之间切换；
- 中文环境友好：界面与提示面向中文设计；
- 保持“所见即所得”的列表管理与批量操作，减少误操作与反复查找。

## 常见问题

- 为什么“执行分解”是灰色？
  - 可能未学分解/战斗中/正在读条/背包空格不足/待分解为空；将鼠标悬停在按钮上可查看具体原因。
- 为什么设置面板有时不在原位？
  - 设置面板仅在打开时与主界面对齐一次，之后可拖动到任意位置；再次打开会回到默认位置。
- 如何快速回到初始状态？
  - 使用左侧“Reset”，确认后清空保存数据与排除表。
